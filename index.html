GitHub Pages is serving the wrong source

You are seeing this page (or the README) because Pages is building from a branch. The screener is published by the Nightly scan workflow instead, so a branch build shows the repo root rather than the app.

  1. Open Settings → Pages
  2. Under Source, choose GitHub Actions (not “Deploy from a branch”)
  3. Re-run Actions → Nightly scan, then reload this URL

This file is never served when Pages is configured correctly: the workflow publishes only the docs/ directory, so the app's own page replaces it.
